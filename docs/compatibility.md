# 兼容性与自动适配

## 当前范围

| 环境 | 自动安装行为 | 实测状态 |
| --- | --- | --- |
| Ubuntu 22.04 + GNOME + X11 | 选择系统组件，安装统一蓝白配置 | 配置在 22.04.5 实机使用过 |
| Ubuntu 24.04 及更高版本 + GNOME + X11 | 检测软件源及最低版本后自动安装 | 环境判断有测试，桌面未实测 |
| Ubuntu 22.04 及更高版本 + GNOME + Wayland | 系统 im-config 集成，提示应用与候选框限制 | 环境判断有测试，桌面未实测 |
| Ubuntu 20.04、其他发行版／桌面、非桌面会话 | 停止完整安装并说明原因 | 未实现完整适配 |
| 已有 Fcitx5，仅装主题 | 使用 `--theme-only` | 是否显示取决于当前界面插件 |

自动适配表示安装器根据检测结果选择方案，并在本机编译词库；**不表示已测试所有系统与应用，也不保证未来版本永远兼容**。若新系统移除必需软件包或编译失败，安装会停止，不会强行使用别的 Ubuntu 版本的软件包。

## 自动处理什么？

1. 读取 `/etc/os-release`、桌面名称和会话类型。
2. 查询当前 apt 软件源，要求 Fcitx5 ≥ 5.0.14、fcitx5-rime ≥ 5.0.11、librime-bin ≥ 1.7.3；安装当前软件源候选版本。有 GTK2、GTK4、Qt6 模块时自动补充。
3. 使用系统自己的 `im-config`，让发行版处理登录启动和输入接口，不往 `.bashrc` 拼接环境变量。
4. 下载固定版本雾凇，在本机 Rime 上编译成功后才切换配置。新旧系统都使用原生拼音／英文组件，不自动启用未经验证的 Lua 扩展。
5. 固定上方拼音、横排七候选、候选后无拼音注释、Shift 中英切换、蓝白主题。禁用 Fcitx5 Kimpanel 插件，使用 Classic UI；关闭新版的深色主题与强调色跟随，避免系统主题改变外观。
6. 备份用户配置和 GNOME 输入源，支持恢复；学习词库和自定义短语不会上传到 GitHub。

Qt6 模块在软件源中没有时会明确不安装；依赖该模块的 Qt6 应用不在保证范围。字体缩放、实际候选词顺序会因机器和学习历史而不同。

## Wayland 的边界

Wayland 和 X11 的输入接口、候选框定位方式不同。GNOME 原生 Wayland 应用可能出现候选框定位差异，GNOME Shell 搜索等界面无法保证显示 Classic UI 候选框。Kimpanel 可解决部分桌面集成问题，但会接管主题；本项目默认选择蓝白 Classic UI，因此两者不能保证同时满足。

不会自动切换到 X11、修改浏览器启动参数或注销。如果当前应用在 Wayland 下效果不理想，可以在登录页提供该选项时选择“Ubuntu on Xorg”，再安装或重新登录测试；不要为此强改不支持 Xorg 的系统。

## 已做的检查

- Ubuntu 22.04.5 GNOME/X11 的实际配置：中文候选、英文词条、Shift 中英切换、上方拼音、蓝白主题。
- 自动测试：22.04／24.04／26.04 的环境判断模拟、软件包选择、只读预览、备份恢复、保留安装后的学习数据、符号链接保护。
- 安装脚本的固定版本词库下载、编译与临时目录部署检查。
- **尚未在全新虚拟机执行自动安装的完整桌面验收，也未在其他 Ubuntu 版本运行桌面测试。**

后续每个环境仍需验证：安装、登录启动、浏览器／终端／编辑器输入、长句、中英切换、候选框位置、主题和恢复。
